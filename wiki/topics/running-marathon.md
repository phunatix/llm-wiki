# Running & Marathon Training

**Scope**: Marathon preparation, interval training methodology, and seasonal running planning.

## Core Concepts

- [[concepts/marathon-interval-training]]: The Laufcampus approach to interval training — backward planning from race day
- Periodization: Structuring training in phases (base → threshold → race-specific)
- Six Race Tempos (Laufcampus method): 1RT, 3RT, 5RT, 10RT, HMRT, MRT

## Key Principles

- Train the race tempo last (work backwards from race day)
- Final plan phase (last 5 weeks): Marathon Race Tempo (MRT) intervals
- Middle phase: Half-marathon tempo (HMRT) intervals
- Early phase: 10K tempo (10RT) intervals
- Three key sessions per week: Long Run + Threshold Run + Interval Training

## Seasonal Structure (September marathon target)

```
Winter (Dec–Feb): Base fitness
  → 1-2 runs/week + cross-training + strength/yoga 3-4x
Spring (Mar–Apr): Form check + HM race (~8-12 weeks out)
  → 3 runs/week; 5K or 10K time trial; HM as "B race"
Summer (May–Aug): 10-15 week marathon block
  → 10RT → HMRT → MRT intervals; long runs; test races
Race Week: Light HMRT session Tuesday/Wednesday → race
```

## Key Insights

- Don't start a marathon too fast — even with early banking strategy, you'll blow up at km 35
- A 2km interval at HMRT pace in race week "primes" the neuromuscular system — marathon pace then feels easy
- Cross-training in winter (ski touring, cycling, yoga) maintains cardiovascular base without running injury risk
- Maximum interval volume: 10K tempo → 10km total; HMRT → 14km total; MRT → 24km total
