# Summary

This source is a practical note on why organizations may need an MCP registry rather than ad hoc server references. It focuses on security posture, storage location, provenance, and version control for MCP servers and their exposed tools.

# Key Takeaways

- MCP server governance includes trust, storage, and change control, not just connectivity.
- A registry can function as a control point for publishing and approving MCP servers.
- The article treats MCP tools as organizational assets that need lifecycle management.
