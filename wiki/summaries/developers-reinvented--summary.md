# Developers, Reinvented — Summary

**Author**: Thomas Dohmke (CEO, GitHub)
**Source**: ashtom.github.io/developers-reinvented
**Date**: August 2025 (created 2026-01-31)

## One-Paragraph Summary

Based on interviews with 22 developers who heavily use AI tools, GitHub CEO Thomas Dohmke documents a four-stage developer transformation: AI Skeptic → Explorer → Collaborator → Strategist. At Stage 4, developers have shifted from writing code to orchestrating and verifying AI agents. Half expect 90% AI-written code within 2 years — and view this not as diminishment but reinvention. Essential skills shift from implementation to delegation, verification, and systems thinking.

## Key Claims

- Four-stage adoption model: Skeptic → Explorer → Collaborator → Strategist (see [[concepts/ai-developer-stages]])
- Stage 4 developers focus on delegation (setting up agents) and verification (validating output)
- 50% believe 90% AI-written code is 2 years away; 50% say 5 years
- Success metric shifts from "time saved" to "ceiling raised" — increased ambition, not just efficiency
- AI-heavy developers pay for top-tier subscriptions because they're expanding scope, not reducing effort
- Key new skills: AI fluency, delegation, agent orchestration, verification, product/systems thinking
- Education must be reinvented: teach abstraction/decomposition, not rote syntax; integrate AI into CS curricula

## Key Quote

> "Maybe we become less code producers and more code enablers. My next title might be Creative Director of Code."

## Contradictions

- [[summaries/thoughts-on-slowing-down--summary]] argues that full agent delegation leads to compounding errors and unmaintainable systems — a more cautionary view of Stage 4 behavior
