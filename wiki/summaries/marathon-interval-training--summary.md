# Marathon Interval Training Guide — Summary

**Author**: Andreas Butz (Laufcampus)
**Source**: manager-magazin.de
**Date**: April 2023

## One-Paragraph Summary

Interval training is one of three key weekly training sessions for marathon preparation (alongside the long run and threshold run). Using the Laufcampus method's six race tempos, a 15-week training block is planned backwards from race day: start with 10K pace intervals, progress to half-marathon pace, finish with marathon pace intervals. Race week includes a short HMRT session to prime neuromuscular speed. The system builds fitness, confidence, and a feel for marathon pace.

## Key Numbers

- Author: 180+ marathons completed; 200th planned for Kenya in 2024
- Three key weekly sessions: Long Run + Threshold Run + Interval Training
- Final phase max volumes: MRT = 24km total; HMRT = 14km total; 10RT = 10km total

## Key Tip

> Run 3×2km at HMRT pace 2-3 days before the marathon. This "speed memory" makes marathon pace feel easy at the start — and prevents going out too fast.
