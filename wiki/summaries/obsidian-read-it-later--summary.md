# Obsidian as Read-It-Later App — Summary

**Author**: Nicolas Lœuillet
**Source**: nicolas.loeuillet.org
**Date**: August 2024

## One-Paragraph Summary

Obsidian can replace Pocket, Instapaper, or Wallabag as a read-it-later app using the ReadItLater community plugin. Workflow: copy URL → CMD+Shift+R → article saved as Markdown in vault. Dataview lists unread articles; tags and properties classify them; Share Note plugin shares saved articles with others. Local, plain-text, no vendor lock-in.

## Workflow

1. Copy article URL to clipboard
2. Open Obsidian → CMD+Shift+R (ReadItLater plugin)
3. Article saved as Markdown in vault
4. Tag as `unread`, `favorite`, etc.
5. Dataview query shows unread list
6. Share Note plugin creates public link for sharing

## Key Advantage

Articles saved locally as Markdown — same format as wiki. Feeds directly into LLM wiki ingest workflow.
