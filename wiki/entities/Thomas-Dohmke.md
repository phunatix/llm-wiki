# Thomas Dohmke

**Category**: Person (Tech Executive)

**Quick Summary**: CEO of GitHub; author of "Developers, Reinvented"; conducted interviews with 22 AI-heavy developers to document the transformation of the developer role.

## Overview

Thomas Dohmke is the CEO of GitHub (owned by Microsoft). His 2025 essay "Developers, Reinvented" documents primary research from interviews with 22 developers who heavily use AI tools, tracing the stages of AI adoption and the shift in the developer role from code writing to agent orchestration and verification.

## Key Contributions

- Developed the **four-stage AI adoption model** (Skeptic → Explorer → Collaborator → Strategist)
- Framed the developer role shift: writing code → **delegation + verification**
- Observed that AI-heavy developers measure success by **ambition expanded**, not time saved
- Notes that education must be reinvented alongside the developer role

## Key Quotes

> "Half of them expect 90% AI-written code within 2 years."

> "We should update how we talk about (and measure) success when using these tools... after initial efficiency gains, focus will be on raising the ceiling."

> "Maybe we become less code producers and more code enablers. My next title might be Creative Director of Code."
